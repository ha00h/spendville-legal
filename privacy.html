본 문서는 법률 자문이 아닙니다. 필요 시 전문가 검토 후 개정하세요.

Spendville(이하 “서비스”)는 가계부·마을 꾸미기 앱입니다. 본 방침은 서비스가 어떤 개인정보를 다루는지 안내합니다.

1. 수집하는 정보

항목 목적 수집 방법
Google(및 추후 Apple) 로그인 식별자, 표시 이름 계정 생성·인증, 마을 멤버 표시 소셜 로그인
프로필 사진(선택) 마을 멤버 아바타 사용자가 선택
지출·카테고리·꾸미기·출석·포인트 등 앱 기록 서비스 제공, 기기 간·멤버 간 동기화 사용자 입력
기기 로컬 저장 데이터 오프라인 사용 Drift(SQLite)
(선택) 카드 문자·영수증 사진 내용 지출 자동 채움 붙여넣기·촬영 시, 동의 후 Google Gemini로 전송

광고 SDK·유료 결제·위치·연락처는 수집하지 않습니다.

2. 보관·이전

  • 동기화: Google Firebase Auth, Cloud Firestore (asia-northeast3, 서울 리전)
  • 소셜 로그인 제공자(Google/Apple)의 처리는 각 사 정책에 따릅니다.
  • 붙여넣기·영수증 AI 읽기: 동의 후 Google Gemini(국외)로 해당 내용이 전송됩니다. Google의 처리방침이 적용되며, 앱에서는 읽기 요청에만 사용합니다.

3. 보유 기간

  • 계정 유지 동안 서비스 제공에 필요한 범위에서 보관합니다.
  • 계정 삭제 시 이 기기 데이터와, 가능한 범위의 클라우드 데이터(소유 마을·멤버십·Auth 계정)를 삭제합니다. 다른 사람 마을에 남긴 기록은 “이전 멤버”로 남을 수 있습니다.
  • 관계 법령상 보관이 필요한 경우 해당 기간 보관합니다.

4. 이용자 권리

  • 앱 설정 → 계정 삭제에서 삭제를 요청할 수 있습니다.
  • 웹 안내: 계정 삭제 페이지
